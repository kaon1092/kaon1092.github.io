다중 로봇 지능 연구 —
P2P 기반 MRTA 검증용 HILS 테스트베드 구축

다중 로봇 작업 할당(MRTA) 알고리즘은 보통 시뮬레이션으로만 검증되어 실물 환경과의 괴리, 중앙집중식 통신 의존, 높은 실험 비용이라는 한계를 갖습니다. 이를 해결하기 위해 저가형 소형 로봇 MONA와 ESP-NOW P2P 통신을 활용해, 시뮬레이션(SILS)에서 검증한 MRTA 알고리즘을 실물 하드웨어(HILS)로 확장 검증하는 테스트베드를 구축했습니다.

Multi-RobotMRTAHILSESP-NOW P2PMONA

SILS → HILS 검증 과정

동일한 다중 로봇 협업(작업 할당) 알고리즘을 ① 시뮬레이션에서 검증(SILS)한 뒤, ② 실물 MONA 로봇 테스트베드(HILS)로 확장했습니다. 오른쪽 HILS 테스트베드 구축이 제가 담당한 부분입니다.

① SILS — 시뮬레이션 검증

SPACE 시뮬레이터 기반 다중 로봇 작업 할당 알고리즘 검증

② HILS — 실물 로봇 검증 (담당 구축)

동일 알고리즘을 MONA 실물 로봇 + P2P 통신으로 실시간 검증

테스트베드 시스템 구성

천장 카메라 — MONA에 부착된 WhyCode 마커 촬영 → 마커 인식 — 각 로봇의 위치·자세 추정 → 좌표 변환 — SPACE 시뮬레이터의 2차원 픽셀 좌표계로 변환 → MONA Client — Task까지의 상대 거리·각도 계산 후 명령 전송 → MONA 로봇 — 명령 수행, 로봇 간 ESP-NOW P2P로 메시지 상호 교환 → MRTA 알고리즘 — 교환된 정보 기반 분산 작업 할당 (conflict 해소)

담당 역할 — HILS 테스트베드 구축

  • MONA 소형 로봇의 주행 제어·장애물 회피 동작 구현 (ESP32 임베디드)
  • ESP-NOW 기반 P2P 통신으로 중앙 서버 없이 로봇 간 직접 메시지 교환 구조 적용
  • 카메라 측위 – 시뮬레이터 – 실물 로봇을 연동하는 실시간 검증 루프 구성 및 실험
  • SILS 검증 알고리즘의 HILS 이식 과정에서 발생하는 시뮬-실물 괴리(동역학·통신 지연) 분석
